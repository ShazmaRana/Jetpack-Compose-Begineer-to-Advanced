# Jetpack Compose: Beginner to Advanced 🚀

This repository contains my learning journey with **Jetpack Compose**, from the basic concepts to more advanced Android development.

I am learning each topic by understanding the concept first and then building a small practical project to apply what I learned.

Each topic contains:

* 📚 A topic-specific README
* 💻 A complete Android project
* 📸 Screenshots of the project
* 📝 Notes about what I learned
